InferCausalGraph

Implementation of the LLCB method of Weinstock & Arce et al., Cell Genomics 2024, refactored in version 0.3 for calibrated total-effect estimation and a scalable sampler.

Overview

LLCB estimates a matrix of direct effects B (parents in rows, children in columns) from perturbation experiments, by matching the total effects implied by B to total effects estimated from the data. Fitting proceeds in two stages.

Stage 1 — interventional total effects

For each perturbed gene u, all readouts are regressed jointly on [intercept, knockout indicator, donor dummies] over the samples in KO(u) ∪ controls. Writing Δ for the knockout-indicator coefficients, the normalised total effect is the Wald ratio Θ[u, j] = Δ[j] / Δ[u], whose delta-method covariance is returned alongside it.

InferCausalGraph.estimate_total_effects — Function
estimate_total_effects(x, interventions, donors, controls; kwargs...) -> TotalEffectEstimate

Donor-adjusted interventional total effects with standard errors.

For each perturbed gene u, all readouts are regressed jointly on [intercept, knockout indicator, donor dummies] over the samples in KO(u) ∪ controls. Writing Δ for the knockout-indicator coefficients, Θ[u, j] = Δ[j] / Δ[u], with the delta-method covariance of that ratio.

Keyword arguments

  • log_normalize = false: apply log1p first (matches the old fit_model path).
  • center = true, scale = true: centre by control means and scale by control standard deviations, as in the published implementation. Θ is invariant to centring; scaling reparameterises B[i, j] to B[i, j] σ_i / σ_j.
  • covariance = :diagonal: :diagonal keeps per-entry variances only; :full additionally returns the p × p within-knockout covariance.
  • shrink = true: apply Schäfer–Strimmer shrinkage to the residual covariance (only relevant for covariance = :full).
  • min_knockdown = 0.25: rows whose knockdown contrast is smaller than this multiple of its own standard error are marked inactive instead of producing an unstable ratio.
  • threads = true: estimate knockout rows in parallel.

x is n × p expression, interventions[i, j] == 1 marks sample i as a knockout of gene j, donors is a per-sample donor code and controls flags the unperturbed samples. This method depends on nothing outside the standard library, which keeps the stage-1 estimator testable without the modelling stack; see graph.jl for the interventionGraph wrapper.

InferCausalGraph.TotalEffectEstimate — Type
TotalEffectEstimate

Stage-1 estimate of the interventional total-effect matrix, together with the sampling uncertainty that stage 2 needs in order to weight it.

Fields

  • Θ::Matrix{Float64}: q × p. Θ[u, j] is the total causal effect of a one-unit intervention on the u-th perturbed gene on readout j. The self-effect entry is stored as 0; the implied Θ̃ carries 1 there.
  • se::Matrix{Float64}: delta-method standard errors of Θ.
  • Σ::Union{Nothing,Vector{Matrix{Float64}}}: if covariance = :full, Σ[u] is the p × p sampling covariance of row u of Θ. Estimates within a row share control samples and are correlated; estimates in different rows share only the controls.
  • knockdown::Vector{Float64}: the donor-adjusted contrast achieved on the perturbed gene itself (the Wald denominator).
  • knockdown_se::Vector{Float64}: its standard error. |knockdown / knockdown_se| is the first-stage t statistic; see weak_knockdowns.
  • active::BitMatrix: entries that stage 2 should use (false on self-effects and on rows whose knockdown was too weak to identify a ratio).
  • nobs, dof: samples and residual degrees of freedom per knockout.
  • perturbed::Vector{Int}: column index of each perturbed gene.
  • targets::Vector{String}: readout names, length p.

InferCausalGraph.weak_knockdowns — Function
weak_knockdowns(te; threshold = sqrt(10)) -> Vector{Int}

Rows of te whose knockdown is weak in the instrumental-variable sense: the first-stage t statistic |knockdown / knockdown_se| is below threshold (the default is the usual first-stage F > 10 rule). Wald ratios in those rows have heavy-tailed sampling distributions. Their standard errors are large, so they carry little weight in fit_llcb, but they can dominate any unweighted use of the total effects, including closed_form_coefficients.

InferCausalGraph.schafer_strimmer_shrinkage — Function
schafer_strimmer_shrinkage(R, dof)

Analytic shrinkage intensity for a covariance matrix estimated from residual matrix R, shrinking the correlations toward zero (Schäfer & Strimmer 2005). Replicates per knockout are far fewer than readout genes, so the unshrunk residual covariance is singular and cannot be used for weighting as is.

source

Knockout rows whose first-stage F statistic falls below 10 are weak: their Wald ratios have heavy-tailed errors. estimate_total_effects warns about them. They carry little weight in fit_llcb because their standard errors are large, but they distort any unweighted use of the total effects.

Stage 2 — the exact moment model

Under a hard intervention the normalised total-effect matrix is

\[\tilde{T} = \mathrm{Diagonal}(\mathrm{diag}(A))^{-1} A, \qquad A = (I - B)^{-1}\]

Row $u$ of $A(I-B) = e_u^\top$ gives $A[u,v] = \sum_w A[u,w] B[w,v]$ for $v \neq u$; dividing by $A[u,u]$ is exactly the recursion "total effect on $v$ equals the sum over parents of (total effect on the parent) times (direct effect)". This is not $(I-B)^{-1}$ unless the graph is acyclic — a hard knockout cuts the edges into the perturbed gene, so feedback loops through it must be removed, which is what the row normalisation does.

Because the model sits on the left of the moment condition and the data only on the right, the noisy total effects never act as a design matrix, which is what removes the attenuation of the original $t = T\beta$ formulation.

InferCausalGraph.llcb_model — Function
llcb_model(te::TotalEffectEstimate; kwargs...) -> LLCBModel

Build the stage-2 log-posterior from stage-1 output.

Weights are the reciprocal stage-1 sampling variances, so the free per-block σ of the original model is replaced by uncertainty that was actually estimated. An optional dispersion φ can rescale all of them, but it is off by default because the LLCB design leaves no residual degrees of freedom to identify it (see estimate_dispersion).

Keyword arguments

  • prior = :studentt: one of :normal, :studentt, :horseshoe. :studentt keeps the parameter count at p(p-1) + 2 and is the scalable default; :horseshoe is the regularised horseshoe of Piironen & Vehtari (2017) in non-centred form, which adds p(p-1) + 2 auxiliary parameters.
  • prior_scale = nothing, prior_df = 3.0: scale and degrees of freedom for :normal / :studentt. When nothing, the scale is set to the median absolute observed total effect, which puts the prior on the same scale as the coefficients; a scale far below the true magnitudes pushes the posterior into the prior's tail and degrades sampling.
  • tau0 = 0.01, slab_scale = 0.5, slab_df = 4.0: horseshoe hyperparameters.
  • rho_max = 2.0, stab_scale = 0.5: a smooth penalty on the largest singular value of B, acting only as a guard against divergence. It is deliberately loose: σ_max(B) ≥ ρ(B), often by a wide margin, so a tight bound on the singular value would forbid perfectly legitimate cyclic networks and, being stiff, would collapse the sampler's step size. The hard guard against a non-invertible I - B is separate and always on. This replaces the original spectral_radius penalty, which seeded power iteration with Base.rand inside the model – making the log density stochastic and its gradient irreproducible – and which in any case returned the spectral radius of the elementwise square W ∘ W rather than of W.
  • estimate_dispersion = nothing: whether to sample log φ. The default turns it on only when there are residual degrees of freedom (more weighted moments than coefficients), which never happens in the standard LLCB design; see the comment in the function body. false fixes φ ≡ 1.
  • weight_floor = 1e-8: guards against division by a vanishing standard error.

InferCausalGraph.closed_form_coefficients — Function
closed_form_coefficients(T̃) -> Matrix

Invert the moment identity exactly. With T̃ = Diagonal(d)⁻¹ A and A = (I - B)⁻¹, I - B = T̃⁻¹ Diagonal(d)⁻¹; the zero diagonal of B forces d[j] = (T̃⁻¹)[j, j], so

B = I - T̃⁻¹ Diagonal(diag(T̃⁻¹))⁻¹ .

T̃ must be the full p × p normalised total-effect matrix with unit diagonal, i.e. every readout must also have been perturbed. With noise-free total effects this recovers B exactly; with estimated ones it is the method-of-moments estimator, which is where the MAP converges under a flat prior because the system is just-identified. It provides no sparsity, and it amplifies noise when T̃ is ill-conditioned.

Inference

MAP by L-BFGS on the analytic gradient, then Pathfinder for a warm start and a diagonal-plus-low-rank metric, then NUTS. The metric matters: the moment likelihood is strongly anisotropic, and a diagonal metric drives step-size adaptation toward zero.

InferCausalGraph.fit_llcb — Function
fit_llcb(te::TotalEffectEstimate; kwargs...) -> (fit::LLCBFit, model::LLCBModel)

Fit the LLCB direct-effect matrix from stage-1 total effects.

Runs MAP by L-BFGS, preconditions with Pathfinder, then samples nchains NUTS chains in parallel across Julia threads.

Keyword arguments

  • prior, prior_scale, prior_df, rho_max, ... : forwarded to llcb_model when model is not supplied.
  • model: a prebuilt LLCBModel, bypassing construction.
  • nchains = max(2, min(4, Threads.nthreads())), n_adapt = 800, n_samples = 800, target_accept = 0.9, max_depth = 10.
  • use_pathfinder = true, pathfinder_runs = 4, pathfinder_jitter = 0.5: run Pathfinder from dispersed starts around the MAP and use the covariance of its best path (by ELBO) as the HMC metric. Starting Pathfinder at the MAP gives a degenerate curvature estimate and an unreliable metric.
  • retry_on_poor_mixing = true, rhat_tolerance = 1.05, divergence_tolerance = 0.02: if the Pathfinder metric yields chains that fail these thresholds, the sampling pass is repeated once with a diagonal metric seeded from the Pathfinder variances and full Stan-style adaptation, and whichever pass mixed better is reported.
  • blas_threads = :auto: BLAS threads during sampling; :auto uses one thread when chains run in parallel, which avoids oversubscribing cores.
  • max_stored = 500: draws are thinned so that at most this many per chain are kept for quantiles and diagnostics; means, standard deviations, sign probabilities and PIPs are accumulated online over every draw.
  • pip_threshold = 0.05: the effect-size cut used for pip.

InferCausalGraph.fit_llcb_closed_form — Function
fit_llcb_closed_form(te::TotalEffectEstimate; ndraws = 4_000, rng, kwargs...) -> LLCBFit

Direct effects without MCMC: draw total-effect matrices from the stage-1 sampling distribution and push each through closed_form_coefficients.

Each draw costs one p × p inversion, so this scales to thousands of genes. It needs every readout to have been perturbed. Two limitations relative to fit_llcb are worth keeping in mind: there is no shrinkage prior, so every edge gets a non-zero estimate and lsfr is the only sparsity signal; and the intervals reflect stage-1 sampling error only, with no model-error dispersion φ.

Rows are resampled with the full within-knockout covariance when te carries it (estimate_total_effects(...; covariance = :full)) and with independent per-entry standard errors otherwise. Draws whose total-effect matrix is singular are discarded and counted in diagnostics[:singular_draws].

LLCBFit

Posterior summaries for the direct-effect matrix B.

Fields

  • diagnostics: step sizes, divergence counts, acceptance, timings, the dispersion φ, which metric was used, and the spectral radius of the posterior-mean B.

InferCausalGraph.fit_cyclic_model — Function
fit_cyclic_model(g::interventionGraph; kwargs...)

Fit the LLCB cyclic model and return (fit, model, total_effects).

Two stages:

  1. estimate_total_effects forms donor-adjusted interventional total effects together with their sampling uncertainty.
  2. fit_llcb fits the direct-effect matrix B against the exact moment condition T̃ = Diagonal(diag(A))⁻¹ A, A = (I - B)⁻¹, weighted by that uncertainty, by NUTS on an analytic gradient.
julia> graph = interventionGraph(expression);

julia> fit, model, te = fit_cyclic_model(graph);

julia> edges = parse_llcb_fit(fit);

Keyword arguments

Stage 1: log_normalize, center, scale, covariance, min_knockdown. Stage 2: prior, prior_scale, prior_df, rho_max, nchains, n_adapt, n_samples, target_accept, use_pathfinder, pip_threshold, seed. All stage-2 arguments are forwarded to fit_llcb.

source
fit_cyclic_model(g, log_normalize, model_pars, sampling_pars)

Compatibility method for the published call signature. The old model_pars and sampling_pars named tuples are mapped onto their closest equivalents: :l1_penalty sets the prior scale, :warmups the adaptation length and :samples the number of retained draws. :R_scale, :l2_penalty, :β_sum_scale, :θ_scale, :ω_scale and :σₓ_scale no longer have counterparts – donor and gene offsets are handled in stage 1 and the noise scale is estimated rather than assumed – and are ignored.

source

When every readout was also perturbed, the moment identity can be inverted in closed form, B = I − T̃⁻¹ Diagonal(diag(T̃⁻¹))⁻¹. fit_llcb uses that point to start the MAP, and fit_llcb_closed_form resamples stage-1 total effects through it to get uncertainty without MCMC (one p × p inversion per draw).

The dispersion φ that rescales the stage-1 standard errors is fixed at 1 by default. With q perturbed genes there are q(p − 1) ≤ p(p − 1) moments for p(p − 1) coefficients, so no residual degrees of freedom inform φ, and sampling it creates a funnel that NUTS cannot traverse.

Edge evidence

parse_llcb_fit reports both lsfr, the local sign false rate min(P(B>0), P(B<0)), and PIP, P(|B| > pip_threshold). Prefer lsfr: it requires no effect-size cut, whereas the published output thresholded at a fixed |β| > 0.05.

The published method

The published Turing-based stage 2 is ported to current Turing with the same settings as v0.2.0b: each Pathfinder run is initialised from Uniform(−0.03, 0.03) and optimised with LBFGS(m = 8). For bit-for-bit reproduction of published numbers, use tag v0.2.0b on Julia 1.9.4.

InferCausalGraph.fit_cyclic_model_legacy — Function
fit_cyclic_model_legacy(g, log_normalize, model_pars, sampling_pars; kwargs...)

The published LLCB stage 2: build the block system with get_cyclic_matrices, fit joint_cyclic_model by multi-path Pathfinder, and report Pathfinder's approximation as the posterior.

model_pars and sampling_pars are accepted for signature compatibility; as in the published analysis, the priors are those set in joint_cyclic_model and the posterior is Pathfinder's approximation.

Keyword arguments

  • rng = Random.default_rng(): the published code used the global RNG.
  • init = :uniform: :uniform matches the published analysis (every run starts from Uniform(-0.03, 0.03)); :published starts from the moment-based point computed in fit_cyclic_model.
  • nruns = 5, ndraws = 2_000, ndraws_elbo = 100, ntries = 1_500, importance = true: as published.
  • adtype = AutoForwardDiff(): the published code set the ForwardDiff backend.

Returns (chains, posterior_adjacency, model, pathfinder_result) as before, so parse_cyclic_chain(result[1], result[2], edges) keeps working.

InferCausalGraph.joint_cyclic_model — Function
joint_cyclic_model(nv, pars, T, t)

The published LLCB stage-2 model: t ~ MvNormal(T β, Diagonal(exp.(σ)²)) over the block system built by get_cyclic_matrices, with a Normal(0, 1) prior on each direct effect, a spectral-radius penalty and a column-sum penalty on the adjacency matrix. Returns the nv × nv adjacency matrix W.

W[a, b] = β[(a - 1)(nv - 1) + b - (b > a)], so with edges from get_cyclic_matrices, coefficient β[z] for edge edges[z] = (i => j) is W[j, i]; parse_cyclic_chain reads it that way.

Note that spectral_radius seeds power iteration with Base.rand, so this model's log density is not a deterministic function of its parameters. That is kept as published.

InferCausalGraph.get_cyclic_matrices — Function
get_cyclic_matrices(g, log_normalize, center = true, scale = true)

Legacy stage-2 construction: the block-diagonal system t = T β used in Weinstock & Arce et al. Retained for reproducibility only – it is no longer part of the fitting path.

source
spectral_radius

spectral_radius(W) returns the largest eigenvalue of the elementwise square W ∘ W, not of W, and seeds power iteration with Base.rand, so successive calls on the same input differ. It is no longer used in the fitting path; the stability guard in llcb_model is deterministic and differentiable.
